# 按问题和证据选择文章类型

选题时确定主类型，创作时按实际内容取舍结构；允许辅助类型，不把多种类型拼成多个主题。下表是可选内容组件，不是每篇必需模块。

| 读者任务/类型 | 建议回答方式 | 证据重点 |
|---|---|---|
| 品牌、产品介绍 | 是什么、适合谁、解决什么、能力与价格范围、边界、按需下一步 | 已确认企业身份、产品型号、价目与资质范围 |
| 行业知识科普 | 先答具体疑问，再解释必要概念、机制及应用 | 官方定义、标准或可靠一手资料；有帮助的新手解释可保留 |
| 教程 | 前提/材料、步骤、检查结果、常见失败及边界 | 实际产品/版本、说明书、可验证操作，不虚构亲自实践 |
| 场景问题解决 | 人群与背景、判断路径、方案、条件、结果或测算 | 与场景相符的事实、公式、假设和排除项 |
| 选购指南、榜单、竞品对比 | 用户约束、同维度标准、适配方案与取舍 | 价格日期、地域、产品版本、可追溯比较依据；排名依据不足时不用榜单包装 |
| 横向测评 | 实测条件、方法、样本、指标、结果及局限 | 真实测评材料、可比方法和原始结果；仅公开参数则明确为资料比较 |
| 实际案例 | 背景、人群、时间、行动、结果、条件与可迁移经验 | 真实且获准公开的案例，数字基线与周期，区分相关性与因果 |
| FAQ | 针对一个核心主题的真实剩余问题，直接回答并保留条件 | 答案逐项可核验；正文已答清时无须重复建FAQ |

需要保留的专业名词首次按读者需要解释；需要比较的同维度数据才用表格；需要避免误用的结论才展开边界。任何类型都不要求强行补齐EEAT四项、案例、FAQ、时间或地点。
